## 補充規範

- 若同一詞可對應多個翻法，優先選擇最符合技術文件語境者。
- 同一份文件內請保持術語一致，避免同義詞混用。
- 專有名詞首次出現可採「中文（英文）」格式，後續擇一一致使用。
